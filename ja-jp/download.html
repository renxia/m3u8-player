M3U8-DLダウンローダークライアントの特徴

@lzwme/m3u8-dl は、強力なm3u8ファイルビデオバッチダウンロードツールで、マルチスレッドダウンロード、ダウンロード中の再生、キャッシュ再開などの機能をサポートしています。

主な特徴

  • Dockerデプロイ、PCクライアント、CLIコマンドラインツールなどのインストール方法をサポート
  • マルチスレッドダウンロード：スレッドプールを使用したマルチスレッドダウンロード
  • ダウンロード中の再生：キャッシュされたtsファイルを使用したオンライン再生をサポート
  • バッチダウンロード：複数のm3u8 URLをバッチでダウンロード
  • キャッシュ再開：失敗したダウンロードのキャッシュを保持し、失敗したセグメントのみを再試行
  • 暗号化サポート：一般的なAES暗号化ビデオストリームの復号化をサポート
  • フォーマット変換：MP4への自動変換をサポート（ffmpegが必要）
  • 検索機能：標準APIを使用したコマンドラインインタラクションによる検索とダウンロードをサポート
  • WebUI：ダウンロードセンターを提供し、WebUIサービスとして起動してダウンロード管理をサポート

CLIコマンドラインツールのインストールと使用

グローバルインストール：

npm i -g @lzwme/m3u8-dl
m3u8dl -h

npxを使用：

npx @lzwme/m3u8-dl -h

Dockerデプロイ

Dockerコマンドで実行：

docker run -d --name m3u8-dl -p 6600:6600 -v ./downloads:/app/downloads -v ./cache:/app/cache lzwme/m3u8-dl

docker-composeで実行：

version: '3'
services:
  m3u8-dl:
    image: lzwme/m3u8-dl
    container_name: m3u8-dl
    ports:
      - "6600:6600"
    volumes:
      - ./downloads:/app/downloads
      - ./cache:/app/cache
    restart: unless-stopped

デプロイ後、http://localhost:6600 にアクセスしてWebUIインターフェースを使用できます。

M3U8オンラインダウンロードと変換ツール

M3U8-DLダウンローダーは強力なバッチダウンロード機能を提供します。
ただし、単一のビデオをダウンロードしたい場合は、オンラインツールをお試しください： M3U8 ビデオからMP4へのオンラインコンバーター
