# DevTools 开发工具

## 功能概述

DevTools 是仅在开发环境下可用的调试工具集，用于监控应用性能和缓存状态。

## 使用方式

### 1. 悬浮按钮

在开发环境下，页面右下角会显示一个 **🛠️ DevTools** 按钮，点击即可打开/关闭性能监控面板。

### 2. 快捷键

- **Windows/Linux**: `Ctrl + Shift + D`
- **macOS**: `Cmd + Shift + D`

## 组件结构

```
src/components/DevTools/
├── index.tsx           # DevTools 入口组件
├── PerformancePanel.tsx # 性能监控面板
└── README.md          # 本文档
```

## 功能特性

### PerformancePanel - 性能监控面板

实时显示以下性能指标：

#### 🎬 播放性能
- 总播放时长
- 播放时长
- 缓冲时长和次数
- 缓冲率
- 错误统计（错误次数和类型）

#### 💾 缓存性能
- 缓存命中率（颜色指示：绿色 > 80%，红色 < 80%）
- 平均响应时间
- 读写删除操作统计
- URL Hash 命中率

#### 🌐 网络性能
- 带宽统计（平均、最小、最大、标准差）
- 断开/重连次数
- 离线总时长

#### 操作按钮
- **导出报告**: 将当前性能指标导出到控制台（JSON 格式）
- **重置指标**: 清空所有监控数据

## 注意事项

1. **仅开发环境**: DevTools 组件只在 `import.meta.env.DEV === true` 时渲染
2. **状态持久化**: 面板显示状态保存在 localStorage 中，刷新页面后保持
3. **性能影响**: 监控面板对性能影响极小，但建议生产环境关闭
